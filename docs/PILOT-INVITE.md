# Convite para o piloto — rascunho

Enviar pelo proprietário somente depois de preparar o caminho escolhido e informar a revisão/pacote e suas limitações. Este documento não envia mensagens nem registra participantes.

> Estou preparando a Mia, uma IA pessoal open source para reunir suas notas e conversas e ajudar a retomar trabalho com fontes.
>
> Quero convidar você para uma sessão de 45–60 minutos testando a experiência do zero. Você escolhe instalar no próprio computador ou usar uma instalação privada em servidor; confirmaremos antes quais opções estão disponíveis nesta rodada. Seus dados ficam na instalação escolhida, separados dos meus e dos demais participantes.
>
> Traga, se quiser, notas Markdown, um vault Obsidian ou exports suportados de ChatGPT/Claude. Importar e buscar funcionam sem IA. Se optar por um modelo, verá o destino e autorizará cada pedido; API pode cobrar por uso e assinatura de chat não é crédito de API.
>
> O objetivo é descobrir se você consegue instalar, importar, retomar um projeto com fontes e continuar depois de fechar o navegador. É uma alpha; vamos informar limitações e orientar backup. Você pode parar quando quiser e não precisa compartilhar notas, históricos ou chaves comigo.
>
> Com sua autorização, registraremos tempo até o primeiro resultado útil, pontos que exigiram ajuda e um relato de qualidade/entendimento. Os resultados compartilhados serão minimizados; você poderá revisar a síntese antes de publicação.

Antes de enviar, preencher **versão/revisão, opção de instalação disponível, pacote/instruções, horário e canal de retorno** fora do repositório. O convite não promete economia, suporte universal ou instalador Mac assinado enquanto esses itens não forem comprovados.
