# Development rules
- Build Mia as an independent, self-hosted personal AI harness.
- Keep all user data, conversations, vaults, secrets and source-project history out of this repository.
- Extract source files only after reviewing licenses, dependencies and personal references.
- Preserve legally required dependency notices.
- Start installations empty; imports are explicit user actions.
- Keep providers and commercial infrastructure optional.
- Enforce identity, tool permissions, action approval and budgets on the server.
- Persist execution state and prevent duplicate effects.
- Clearly distinguish implemented behavior, planned behavior and unverified claims.
- Never claim savings or fixed monthly cost without measurements.
- Test complete user flows and restoration, not only builds.
